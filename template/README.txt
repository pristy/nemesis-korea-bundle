Nemesis Korea Bundle v1.0.0 (올인원 USB 무선 프로젝션 설치 팩)
한국 현대·기아 Gen5W(표준형 5W세대) 전용 무선 카플레이 / 안드로이드 오토
========================================================================

【 준비 사항 】
1. 32GB 이하 USB 메모리를 반드시 [FAT32] 형식으로 포맷합니다.
2. 압축 파일 내부의 내용물(ota_package.tar, NEMESIS.data, README.txt, packages 폴더)을
   USB 메모리의 '최상위(루트)'에 그대로 복사합니다. (폴더째 넣지 마세요!)

【 차량 설치 3단계 】
1. [1단계: NEMESIS 코어 설치]
   - 차량 시동을 켜고(엔진 켬 또는 READY 상태) USB를 내비 전용 데이터 포트에 꽂습니다.
   - [설정] > [일반] > [SW 정보]에서 엔지니어링 모드로 진입합니다.
   - [USB Copy] > [DSP] > [Update OTA] 버튼을 터치합니다.
   - 화면에 설치 메시지가 뜨고 내비가 자동으로 1회 재부팅됩니다.
   ※ 주의: 이때 USB를 절대 뽑지 마시고 그대로 꽂아두세요!

2. [2단계: HMG-API 및 Korea Projection 설치]
   - 내비 화면이 완전히 켜지면 NEMESIS 패키지 스토어가 자동으로 팝업됩니다.
   - 목록에서 [HMG-API]의 [Install]을 먼저 터치하여 설치합니다.
   - 설치 완료 후 [Korea Projection]의 [Install]을 터치하여 설치합니다.
   - 화면에 "설정을 마쳤습니다" 알림이 나올 때까지 약 1~3분간 기다립니다.

3. [3단계: 완전 재부팅 (가장 중요!)]
   - 설정이 완료되면 USB를 뽑아도 됩니다.
   - 시동만 끄면 절전 모드로 들어가므로 설정이 반영되지 않습니다.
   - 반드시 NEMESIS Manager의 [Settings] > [Reboot]를 누르거나,
     내비게이션 본체의 RESET 구멍(작은 핀홀)을 볼펜/클립으로 1초간 눌러 완전히 재부팅합니다.

【 무선 연결 】
- 내비가 켜지면 스마트폰의 Wi-Fi와 블루투스를 켜고 차량과 블루투스로 연결합니다.
- 잠시 후 화면에 무선 안드로이드 오토 또는 무선 카플레이가 케이블 없이 자동 실행됩니다!
