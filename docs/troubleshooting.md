# 문제 해결 및 상세 가이드 (Troubleshooting)

## 1. 완전 재부팅(Hard Reset) 가이드 (필수 단계)

현대/기아 내비게이션은 시동을 꺼도 절전 모드(QuickBoot)로 유지되어 백그라운드 데몬 및 시스템 권한이 즉시 로드되지 않습니다. Korea Projection 설치 후 반드시 **완전 재부팅**을 진행해야 합니다.

### 방법 A: RESET 작은 구멍(핀홀) 누르기 (가장 확실)
* 센터페시아 오디오 볼륨 노브 근처 또는 SD카드 슬롯 옆에 샤프심 크기의 작은 구멍이 있습니다.
* 클립이나 볼펜 끝으로 **1초간 딸깍** 누릅니다.
* 화면이 꺼지며 현대/기아 로고와 함께 시스템이 완전히 처음부터 재부팅됩니다.

### 방법 B: NEMESIS Manager 앱에서 재부팅
* MAP/NAV 버튼 3회 클릭으로 NEMESIS Manager를 엽니다.
* **[Settings] ➔ [Reboot]** 메뉴를 터치합니다.

---

## 2. 순정 원상복구 (Wipe / 출고 상태 복원)

차량 보증 수리, 정기 점검, 블루핸즈 입고 시 언제든지 흔적 없이 순정 상태로 되돌릴 수 있습니다.

### 원클릭 롤백 절차
1. NEMESIS Manager를 실행합니다 (MAP/NAV 버튼 3회 연타).
2. **[Settings] ➔ [Wipe NEMESIS]** 메뉴를 선택합니다.
3. 삭제 안내 팝업과 최종 확인 팝업에서 모두 **[Yes]**를 누릅니다.
4. 백그라운드에서 백업되어 있던 순정 파일들이 모두 복구되고 시스템이 재부팅됩니다.
5. 시스템이 켜지면 공장 출고 당시의 순정 상태로 100% 복원됩니다.

## 3. 순정 내비 업데이트 후 무선 안드로이드 오토 연결 불가 해결 (★ 실전 해결기)

순정 내비게이션 정기 업데이트(예: 260902 빌드 등) 이후 NEMESIS와 번들 패키지를 정상적으로 재설치했음에도, **무선 안드로이드 오토가 자동으로 연결되지 않거나 내비 화면에 팝업이 전혀 뜨지 않을 때**의 종합 해결 가이드입니다.

### 📌 겪기 쉬운 증상 (실제 사례)
* NEMESIS Manager ➔ Korea Projection ➔ **Launch** 화면이 🟢 **초록색("무선 카플레이·안드로이드 오토 준비됨")**으로 뜸.
* 차량 데이터 포트에서 설치용 USB 메모리도 뽑아둠.
* 내비 설정에서 `[Android Auto 사용]` 체크박스 켜져 있음.
* 스마트폰의 `[위치(GPS)]` 켜져 있고, `[Wi-Fi]`도 켜져 있음 (어디에도 연결되지 않고 대기 중).
* 스마트폰 Android Auto 설정에서 `[이전에 연결된 차량]`을 삭제하고, USB 케이블로 1회 유선 연결 후 뽑아보기도 함.
* **그런데도 내비 화면에 "무선 Android Auto를 사용하시겠습니까?" 팝업이 전혀 안 뜨고 블루투스(통화/오디오)만 연결된 채 먹통인 상태.**

### 💡 원인 분석: "바이너리나 내비 시스템 문제가 아닙니다!"
* Launch 화면이 🟢 초록색이라면 차량 시스템, 핫스팟(`hostapd`), 펌웨어 후킹 맵은 **100% 정상 작동 중**인 상태입니다.
* 다운그레이드나 바이너리 문제가 아니라, **스마트폰 내부의 Google Android Auto 앱이 업데이트 이전의 만료된 하드웨어 세션 및 무선 핸드셰이크(SPP) 보안 토큰을 로컬 DB에 보관**하고 있기 때문입니다.
* 이 찌꺼기 세션 때문에 블루투스 등록을 지우거나 목록에서 차를 지워도 스마트폰이 차량의 무선 핸드셰이크 신호를 백그라운드에서 조용히 차단(무시)합니다.

### 🔑 결정적 해결 절차 (이 순서대로 진행)
1. **스마트폰 Android Auto 앱 데이터 & 캐시 삭제 (★ 가장 핵심!)**:
   * 스마트폰 **[설정] ➔ [애플리케이션] ➔ [Android Auto] ➔ [저장공간]**으로 이동합니다.
   * **[데이터 삭제]**와 **[캐시 삭제]**를 모두 눌러 앱 내부의 이전 세션 데이터를 완전히 초기화합니다.
2. **블루투스 페어링 재등록**:
   * 스마트폰 [설정] ➔ [블루투스]에서 등록된 차량 기기를 삭제합니다.
   * 차량 내비 [설정] ➔ [기기 연결]에서도 등록된 스마트폰을 삭제합니다.
   * 스마트폰에서 차량 블루투스를 새로 검색하여 연결합니다.
3. **내비 팝업 승인 및 자동 연결**:
   * 블루투스가 새로 연결되면 스마트폰이 정상적으로 디텍트(감지)되면서, 내비 화면에 **"무선 Android Auto를 사용하시겠습니까?"** (또는 [무선 Android Auto 사용]) 안내 팝업이 드디어 정상적으로 나타납니다!
   * **[사용]** 버튼을 누르면 스마트폰이 차량 핫스팟으로 자동 전환되며 무선 안드로이드 오토가 즉시 실행됩니다.

---

### ⚠️ 추가 기본 점검 체크리스트
* **USB 메모리 분리**: 데이터 포트에 USB 메모리가 꽂혀 있으면 차량 시스템(`GPM`)이 유선 연결 대기 상태에 머물러 무선 연결을 차단합니다.
* **스마트폰 Wi-Fi 상태**: 폰의 Wi-Fi가 켜져 있어야 합니다. (어디에도 연결되지 않고 켜져만 있는 상태가 정상입니다.)
* **스마트폰 위치(GPS)**: 구글 보안 정책상 위치(GPS)가 꺼져 있으면 백그라운드 Wi-Fi 핫스팟 자동 탐색이 차단됩니다.
* **순정 폰 프로젝션 설정**: 내비 화면의 **[설정] ➔ [기기 연결] ➔ [폰 프로젝션 설정]**에서 `[Android Auto 활성화]`가 켜져 있는지 확인하세요.
