[블루링크 미개통 팝업 영구 억제 원클릭 USB 사용법]

1. 패키지 개요
   - 본 USB는 현대/기아 Gen5W 순정 내비게이션(Android 4.4.2 KitKat)에서 
     미개통·기간 만료 시 30일(또는 매월)마다 반복 표시되는 
     "블루링크/기아커넥트 서비스 개통 안내" 팝업을 백그라운드 데몬 및 CPU 소모 없이 
     영구적으로 억제하는 원클릭 설치 스크립트입니다.

2. 올바른 USB 루트 구조
   USB 드라이브 최상위:
     ├── NEMESIS.data
     ├── NEMESIS.sh
     └── README.txt

3. 차량에서 실행 방법 (소요 시간: 약 5초)
   1) 시동을 걸고 내비게이션 부팅이 완료될 때까지 대기합니다.
   2) USB를 차량의 순정 데이터 USB 포트(카플레이/안드로이드 오토 포트)에 꽂습니다.
   3) 화면에 NEMESIS 실행 확인 창("Do you want to execute NEMESIS.sh?")이 뜨면 [Yes]를 터치합니다.
   4) 3~5초 내에 화면 상단에 "블루링크 미개통 팝업 억제 적용 완료 (재부팅 권장)" 토스트와 함께
      NEMESIS 완료 알림이 뜹니다.
   5) 확인을 누르고 USB를 뽑습니다.
   6) 볼륨 노브 근처의 작은 RESET 구멍(핀홀)을 클립/볼펜으로 1초간 눌러 재부팅합니다.
      (재부팅 즉시 영구 적용 완료!)

4. 원복 및 백업 안내
   - 실행 시 원본 설정 파일이 단말기 내부(/data/nemesis/backup/) 및 
     USB(backup/ 폴더)에 자동으로 이중 백업됩니다.
   - PC 연결 시 USB 루트의 DISARM_SUCCESS.txt 파일에서 적용 결과를 확인할 수 있습니다.
